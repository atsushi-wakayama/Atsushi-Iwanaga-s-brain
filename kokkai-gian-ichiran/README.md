# 第221回国会 議案の一覧

衆議院ウェブサイトの[議案情報](https://www.shugiin.go.jp/internet/itdb_gian.nsf/html/gian/menu.htm)（第221回国会・特別会）をもとに作成した非公式のまとめサイトです。

## 内容

- 衆法・参法・閣法・予算・条約・承認・承諾・決算その他・決議の9カテゴリ、計146件を収録
- カテゴリ切り替え、議案件名でのキーワード検索、審議状況での絞り込みに対応
- 各行をクリックすると「何についての法案か」「何を変えるか」「提出理由」の解説を展開表示
  - 解説は衆議院サイトに掲載された法律案本文・提出理由を基に作成した補足情報です（衆法・参法・閣法は公式の本文ページから、その他のカテゴリは公開情報から作成）
  - 参法13号・14号は本文が非公開のため解説なし

## ローカルでの起動

```bash
npm start
# または
python3 -m http.server 3000
```

## デプロイ

```bash
npm run deploy
# vercel --prod
```
