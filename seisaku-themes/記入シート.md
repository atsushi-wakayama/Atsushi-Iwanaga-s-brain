# 政策テーマ 記入シート

Wakayama Talk や議会で出てきたテーマを、このフォーマットで書けば
そのままサイトに追加できます。**JavaScript を書く必要はありません。**

## 使い方

1. `new-themes.txt` を開く（このフォルダにあります）
2. 下のフォーマットをコピーして、1テーマ＝1ブロックで書く
3. 書けたら `node add-theme.js --write` を実行（またはファイルを渡してください）
4. サイトに反映されます

複数テーマをまとめて書けます。ブロックとブロックの間は `----`（ハイフン4つ以上）の行で区切ります。

---

## フォーマット（コピーして使う）

```
ID: 
テーマ名: 
ひとこと: 
分野: 
概要: 
課題の現状: 
考え・提案: 
これまでの動き:
- 
- 
ステータス: 
声のもと: 
更新: 
```

---

## 各項目の書き方

| 項目 | 必須 | 内容 | 目安 |
|---|:--:|---|---|
| **ID** | ◯ | URLになる英数字。`/t/ここ` になります。半角英数とハイフンのみ、重複禁止 | `koutsuu-jiko-map` |
| **テーマ名** | ◯ | カードの見出し。名詞で言い切る | 15〜25字 |
| **ひとこと** | | 見出しの上に出る短い一行。狙いや切り口 | 15〜30字 |
| **分野** | ◯ | 下のリストから選ぶ。複数可、`/` で区切る。**最初に書いた分野の島に配置されます** | 1〜3個 |
| **概要** | ◯ | カードを1回押したときに出る文。何の話かが分かる要約 | 40〜80字 |
| **課題の現状** | | いま何が起きているか。数字があれば入れる | 80〜150字 |
| **考え・提案** | | どうすべきか。県・行政に何を求めるか | 80〜150字 |
| **これまでの動き** | | 質疑・要望・視察などの実績。`- ` で1行ずつ | 1行40字前後 |
| **ステータス** | | `検討中` / `議会で質問` / `県が着手` / `実現` から選ぶ（自由記述も可） | |
| **声のもと** | | どこから出た話か。会議名・回次・日付 | `令和8年6月定例会 一般質問` |
| **更新** | | `2026-06` の形式（年-月） | |
| **画像** | | 使う場合のみ。`images/` に置いたファイル名 | `images/ume.jpg` |

### 分野（この中から選ぶ）

医療・福祉 ／ 子育て・教育 ／ 産業・雇用 ／ 農林水産 ／ 防災・インフラ ／ 交通 ／ 環境・エネルギー ／ 行財政改革 ／ 地域づくり

> リストにない分野を使うと、新しい島が1つ増えます。増やしたいときは先に相談してください。

### 書くときのコツ

- **「概要」は結論から**。カードを開くかどうかがここで決まります
- **「課題の現状」には数字を1つ**入れると説得力が出ます（例：平年比43%、3,000人超）
- **「これまでの動き」が最も差がつく項目**です。空だと詳細ページからその欄ごと消えます
- 「〜すべきである」「〜を求めた」など語尾は既存テーマに揃えると読み味が揃います

## 記入例

```
ID: koutsuu-jiko-map-digital
テーマ名: 交通事故・防犯情報のデジタル可視化
ひとこと: 地図アプリ等を活用し、県民が直感的に認識できる情報発信へ
分野: 交通 / 防災・インフラ
概要: 事故情報や不審者情報をGoogleマップ等のデジタルツールへ落とし込み、視覚的に分かりやすく発信する工夫を提案した。
課題の現状: 現状は統計資料やPDFによるホームページ公開にとどまっており、スマートフォン等で一般県民が直感的に把握しやすい形での発信に改善の余地がある。
考え・提案: AIや地図アプリなどのデジタル技術を活用し、県民がより身近に安全意識を高められる視覚的で使いやすい情報発信へシフトすべきである。
これまでの動き:
- 経済警察委員会にて県警のデジタルマップ導入や情報公開状況を質疑
- AIや地図アプリを活用した視覚的な情報発信の検討を要望
ステータス: 議会で質問
声のもと: 令和8年6月 和歌山県議会 経済警察委員会
更新: 2026-06
```

## Google フォームにするときの設問対応

将来フォーム化する場合は、この記入シートがそのまま設問になります。

| 設問 | 形式 | 備考 |
|---|---|---|
| ID | 記述式（短文） | 正規表現 `^[a-z0-9-]+$` で検証 |
| テーマ名 | 記述式（短文） | 必須 |
| ひとこと | 記述式（短文） | |
| 分野 | **チェックボックス** | 選択肢＝上の9分野。最初の1つが配置先 |
| 概要 | 記述式（段落） | 必須 |
| 課題の現状 | 記述式（段落） | |
| 考え・提案 | 記述式（段落） | |
| これまでの動き | 記述式（段落） | 改行区切りで複数 |
| ステータス | **ラジオボタン** | 検討中／議会で質問／県が着手／実現 |
| 声のもと | 記述式（短文） | |
| 更新 | 日付 | 年月のみ使用 |

回答スプレッドシートのCSVから同じ変換スクリプトに流し込めるようにしておけば、
フォーム送信 → サイト反映まで自動化できます。
