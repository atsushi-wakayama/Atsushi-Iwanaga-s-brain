# 政策のいま — 岩永淳志

onceuponatime.co.jp のホーム画面のように、**ドラッグで動く無限グリッド**からカードが
そのまま拡大変形してサブページ（政策課題の詳細）へ入るサイト。

- `data.js` … 政策テーマのデータ本体
- `記入シート.md` / `new-themes.txt` / `add-theme.js` … テーマ追加用の記入フォーマットと変換スクリプト
- `index.html` … サイト本体のひな形（HTML/CSS/JS すべて内包）
- `build.js` … `data.js` から静的ページを生成するスクリプト（依存パッケージなし）
- `images/` … カード用の写真を置く場所（任意）
- `dist/` … 生成物。gitには入れない（Vercelがビルド時に作る）

## ビルドと公開

`data.js` を書き換えて push すれば、Vercel が `node build.js` を実行して
自動で公開される。手元で確認したいときだけ次を実行する。

```bash
node build.js && python3 -m http.server 4321 --directory dist
```

生成されるページ:

| URL | 中身 |
|---|---|
| `/` | トップ（カードのボード） |
| `/t/<id>` | テーマごとの詳細ページ。**テーマ別のOGP付き** |
| `/list` | テキスト一覧 |
| `/sitemap.xml`, `/robots.txt` | 検索エンジン向け |

各ページには title / description / OGP がテーマごとに埋め込まれるので、
LINEやXに個別テーマのURLを貼るとタイトル・説明入りのカードで表示される。
SNSカードに画像を出したい場合は、テーマに `image` を指定するか、
`data.js` の `SITE.ogImage` に共通画像（例 `"images/ogp.png"`）を設定する。
公開URLを変えたときは `SITE.url` も直すこと（OGPとsitemapに使う）。

## テーマを追加する（記入シート方式・おすすめ）

JavaScript を書かずに追加できます。書式は [記入シート.md](記入シート.md) を参照。

1. `new-themes.txt` に、1テーマ＝1ブロックで記入（ブロックの区切りは `----` の行）
2. 確認 → 書き込み → ページ生成

```bash
node add-theme.js          # 下書きの確認（data.js は変更しない）
node add-theme.js --write  # data.js に追記
node build.js              # ページを生成
```

必須項目もれ・IDの重複・分野の誤りはスクリプトが弾くので、
data.js が壊れて画面が真っ白になることがありません。

## 中身の追加のしかた（直接 data.js を編集する場合）

`data.js` の `THEMES` 配列に、オブジェクトを1つ足すだけ。
トップページのカード・絞り込みタグ・一覧・詳細ページが自動で増える。

```js
{
  id: "kaigo-jinzai",              // URL用（#/t/kaigo-jinzai）。英数字・重複禁止
  title: "介護人材の不足",           // カードの見出し
  subtitle: "支え手が先にいなくなる", // 小見出し（任意）
  tags: ["医療・福祉", "御坊・日高"], // 絞り込みに使われる
  image: "images/kaigo.jpg",       // 任意。無ければ自動でグラデ＋文字
  summary: "施設はあるのに人がいない。", // カード裏／詳細の冒頭
  issue:  "有効求人倍率は高止まりし…",   // 課題の現状
  stance: "県独自の処遇上乗せと…",       // 岩永の考え・提案
  actions: ["一般質問で実態把握を求めた"], // これまでの動き（箇条書き）
  status: "議会で質問",              // 検討中／議会で質問／県が着手／実現 など
  source: "Wakayama Talk 第3回（2026/05/12）", // 声のもと
  updated: "2026-09"
}
```

Wakayama Talk で出た声は、`source` に回次・日付を書いて残すと、
「どこから出てきた課題か」が詳細ページに表示される。

現在入っているデータは**サンプル**。実際の内容に差し替えて使う。

## トンマナ（デザインの決まり）

白背景＋深みのあるグリーンが基調。`index.html` の `:root` にまとめてあるので、
色を変えたいときはここだけ触れば全ページに反映される。

```css
--green:#14624a;   /* メインカラー：見出し・ボタン・アンダーライン */
--green-d:#0d4433; /* 濃いほう。タイトルの文字色 */
--green-l:#e9f3ef; /* 薄い緑の面。メタ情報やホバー */
--band:linear-gradient(90deg,#cfeadb,#d8eeea,#d6e7f6); /* 薄緑〜水色の帯 */
--round:linear-gradient(135deg,#2f9070,#14624a,#0d4433); /* 丸いボタン */
```

- **フォント**: タイトル・見出しは明朝体（Noto Serif JP）、本文とナビはゴシック体（Noto Sans JP）
- **ナビゲーション**: ホバーで緑のアンダーラインが左から伸びる
- **グラデーションの帯**: 画面最上部・ポップアップの上端・詳細ページの本文上端・一覧の上端
- **丸いグラデーションボタン**: 概要ポップアップの「→」
- **角丸のピル型ボタン**: 下部の絞り込みタグ（白地＋緑ボーダー、選択中は緑ベタ）
- **カードの色分けはそのまま**。テーマごとの色は視認性のため維持し、白背景の上に影で浮かせている

## 並び方（どこまで見たか分かるように）

- 全テーマが**1枚ずつ**、左上から番号順（01, 02, …）に並ぶ。同じカードが何度も出てくることはない
- ボードの端まで行くと止まる（無限ループしない）。行きすぎるとゴムのように戻る
- 右端の細いバーが**いま全体のどのあたりを見ているか**を示す
- 一度詳細ページを開いたテーマは薄くなり「✓ 見た」が付く。右上に「3 / 12 を見た」と進み具合が出る
  （ブラウザの localStorage に保存。右上の「リセット」で消せる）
- 絞り込みタグを押すと、該当するテーマだけで並べ直す

列数は `index.html` の `CARD.cols`（PC・初期値4）と `CARD.mobileCols`（スマホ・初期値2）で変えられる。

## カードの大きさを変える

`index.html` の JS 冒頭にある `CARD` を書き換えるだけ。

```js
const CARD = {
  width: 340,        // PCでのカード幅(px)
  ratio: 1.04,       // 高さ = 幅 × この値（大きいほど縦長）
  mobileWidth: 0.62, // スマホでは画面幅×この割合が1枚の幅
  gap: 22,           // カード同士の間隔(px)
};
```

`ratio` が縦横比。1.30 が初期の縦長、現在は **1.04**（縦を約80%に短縮）。
グリッドの列数・行数は画面サイズから自動計算されるので、他をいじる必要はない。

## 動かす / 公開する

ローカル確認（このリポジトリのルートで）:

```bash
python3 -m http.server 4321 --directory seisaku-themes
```

http://localhost:4321 を開く。
静的ファイルだけなので、Vercel / Netlify / GitHub Pages にそのまま置ける。

## 操作

| 操作 | 動き |
|---|---|
| スクロール / ドラッグ | ボードを上下左右に動かす（**範囲は有限**。端で止まる） |
| カードを**1回**クリック | 概要ポップアップ（見出し・要約・タグ・ステータス）が出る |
| 同じカードを**もう1回**／ポップアップをクリック | カードが拡大して詳細ページへ |
| Esc | 1回目でポップアップを閉じ、詳細ページなら閉じてトップへ |
| 「一覧へもどる」 | トップへ戻る |
| 下部のタグ | そのタグの課題だけを浮かび上がらせる |
| ALL LIST | テキストの一覧表示 |

URL は `/t/<id>` `/list` になり、それぞれ実体のあるページとして生成される。
サイト内でカードを押したときはページ遷移せず、カードが拡大変形する演出のまま
URLだけが切り替わる（外から直接踏まれたときは静的HTMLが返る）。
