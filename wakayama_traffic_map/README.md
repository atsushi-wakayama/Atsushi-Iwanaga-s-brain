# 和歌山県 交通事故マップ（2019〜2024）

警察庁「交通事故統計情報のオープンデータ」（本票）から**和歌山県内**の事故を抽出し、
コードを名称に変換したうえで、インタラクティブ地図と表（Excel/CSV）にしたものです。

公開地図：https://wakayama-traffic-map.vercel.app

## 収録データ

- 対象：和歌山県（警察庁コード 65）／ 2019〜2024年の6年分
- 件数：**8,896件**（死亡170件・負傷8,726件）
- 出典：警察庁 交通事故統計情報オープンデータ（本票 honhyo_YYYY.csv、Shift-JIS）

| 対象年 | 件数 |
|---|---|
| 2019 | 1,859 |
| 2020 | 1,585 |
| 2021 | 1,419 |
| 2022 | 1,389 |
| 2023 | 1,355 |
| 2024 | 1,289 |

### 物件事故2025（物損）レイヤーの注意点

警察提供の「令和7年中に計上された物件事故」（令和8年6月抽出）に基づく。
本編の人身事故データ（2019〜2024）とは**別カテゴリ・別年次**で、地図では既定OFFの
独立レイヤー。以下の提供元注意事項に留意すること。

- 今後、人身事故への変更等により**件数は変動**する（過去公表値も変動）。
- 計上日基準のため、令和7年発生でない事故も一部含む。
- 事故類型は登録時のもので必ずしも正確ではない。当事者は順不同・3者以上でも2者のみ。
- **緯度経度は大まかな位置**であり、その座標ちょうどで発生したものではない。
- 元データは**日本測地系**。本地図（世界測地系WGS84）に合わせ近似変換して収録している。

## 地図の機能

- 全事故の点プロット（死亡＝赤で強調、負傷＝青）
- ヒートマップ（密集度）
- **⚠️ 事故多発地点**：約44m四方のグリッドで繰り返し発生地点を集計しピン表示（しきい値 2〜5回以上を選択可）
- 年フィルター（全年／各年）。点・ヒートマップ・多発地点・統計・市区町村別件数がすべて連動
- 各点クリックで日時・曜日・死傷者数・市区町村・事故類型・当事者・道路形状・天候を表示

## 再生成方法

警察庁の元データ（`honhyo_2019.csv`〜`honhyo_2024.csv`）と `codebook_2024.xlsx` を
`~/Downloads/` に置いた状態で実行します。

```bash
python3 build_wakayama_map.py    # data.js を生成
python3 build_wakayama_table.py  # xlsx / csv を生成
```

## 注意点（データ仕様）

- 警察庁の都道府県コードは独自体系で、**和歌山県は 65**（30は東京）。
- 緯度経度は世界測地系の度分秒（例 `335706076` → 33°57′06.076″N）。スクリプトで10進度に変換。
- 市区町村は総務省標準地域コード（和歌山県は 30xxx）。県内30市町村を名称に対応。
- **2022年に様式改定があり、2019〜2021は58列・2022〜2024は68列**。旧様式の列位置を新様式に揃えて統合。
- 旧様式固有の車道幅員コード（12/13/16）は歴史的定義で補完済み。
- 各年ファイルには前年発生分が少数含まれるが、ファイル間の重複は0件であることを確認済み。
